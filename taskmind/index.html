Turning spoken thoughts into organised action

Taskmind lets users speak naturally and uses AI to identify tasks, dates, priorities, reminders and calendar events.

Role

Sole Product Designer

Platform

Mobile

Type

Self-initiated exploration

Status

In progress

Problem

People often think faster than they can type. Ideas, commitments and reminders get captured as unstructured thoughts and forgotten before they are organised.

Solution

Input

"Remind me to send the invoice tomorrow morning and schedule a meeting with Tobi next week."

Structured output

"Send invoice: tomorrow morning" & "Schedule meeting with Tobi: next week"

Core features

Voice capture Live transcription AI processing Smart task breakdown Editable task review Calendar integration Smart prioritisation Notifications & reminders Deadline alerts

Target users

Freelancers, students, creatives, busy professionals, founders.

UX considerations

Recording states, live transcription, pause and resume, microphone permissions, noise feedback, transparent AI-processing states, editing before confirmation, failed processing, lost connection, and retry states.

Primary flow

Splash → Onboarding → Permission setup → Authentication → Home → Voice recording → AI processing → Review generated tasks → Edit or confirm → Task dashboard

Visual direction

Deep charcoal, electric blue, white accents.
